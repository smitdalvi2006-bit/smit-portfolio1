# Smit Dalvi — Personal Portfolio

A personal portfolio for my Personal Portfolio Website assignment (MBA Tech, Data Science, NMIMS Mumbai).


**Live site:** add your GitHub Pages link here

## Concept
The site is styled like a car instrument cluster. The needle moves between four "modes" (Gym, Drive, Create, Data) that describe what drives me.

## Built with
- Plain HTML, CSS and JavaScript (no framework, no template)
- Fonts: Barlow Condensed and Instrument Sans, from Google Fonts
